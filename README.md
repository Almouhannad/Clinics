# 🏥 Clinics Project

A full-stack web application for managing clinics, built with ASP.NET Core (.NET 8) for the backend and Angular 18 for the frontend.

## 📁 Project Structure

- `Clinics.Backend/` — ASP.NET Core backend (C#)
- `Clinics.Frontend/` — Angular frontend (TypeScript)

## 🚀 Getting Started

### Prerequisites
- [.NET 8 SDK](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)
- [Node.js (v18+ recommended)](https://nodejs.org/)
- [Angular CLI](https://angular.io/cli)

### Backend Setup
```bash
cd Clinics.Backend
# Open in Visual Studio or run:
dotnet build
# To run the API (adjust project path as needed):
dotnet run --project API/API.csproj
```

### Frontend Setup
```bash
cd Clinics.Frontend
npm install
ng serve -o
```
